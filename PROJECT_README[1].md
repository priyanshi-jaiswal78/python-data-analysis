# Sales Data Analysis

A beginner-friendly Python data analysis project using Pandas and NumPy.

## What this project does

- Loads a sample sales dataset
- Calculates total revenue
- Calculates total units sold
- Finds average transaction value
- Compares revenue by product and category
- Uses NumPy for basic numerical analysis

## Technologies

- Python
- Pandas
- NumPy

## How to run

```bash
pip install -r requirements.txt
python sales_analysis.py
```

## Note

The dataset is a small sample dataset created for learning and demonstration purposes.
